install, white-label, administer and integrate this product.

## Status honesty

Every page keeps the product's status legend where it applies:

- 🟢 **TODAY** — working and verified.
- 🟡 **PARTIAL** — exists, with documented limits.
- 🔵 **TARGET** — explicit roadmap, not implemented.

Nothing marked 🔵 is sold as done.

!!! note "Language fallback"
    Spanish is the primary language of this documentation. Pages not yet translated
    to English are served in Spanish instead of returning an error.
