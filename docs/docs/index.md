marca-blanquean, administran e integran este producto.

## Honestidad de estado

Esta documentación conserva la leyenda de estado del producto en cada página donde aplica:

- 🟢 **HOY** — funciona y está verificado.
- 🟡 **PARCIAL** — existe con límites documentados.
- 🔵 **OBJETIVO** — roadmap explícito, no implementado.

Nada de lo marcado 🔵 se vende como hecho.

    final clínico es **roadmap (P3)**: reusará este mismo sitio (contenedor, white-label, idiomas)
